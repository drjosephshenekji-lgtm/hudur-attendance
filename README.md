# تفقّد الحضور — تطبيق اندرويد يعمل بدون إنترنت

تطبيق لتسجيل حضور الطلاب في الصف **بدون أي اتصال بالإنترنت**.
هاتف المعلّم يشغّل شبكة Wi-Fi محلية وخادمًا صغيرًا، ويعرض رمزي QR على الشاشة.
الطالب يمسحهما بكاميرا هاتفه — **آيفون أو اندرويد** — فتُفتح صفحة يختار منها اسمه،
ويصل التسجيل فورًا إلى جدول المعلّم.

## كيف يعمل في الصف

1. المعلّم يفتح التطبيق ويضغط **ابدأ الحصة**.
2. تظهر على الشاشة بطاقتان:
   - **① اتصال بالشبكة** — مسحه يوصل هاتف الطالب بالشبكة تلقائيًا بلا كلمة مرور مكتوبة.
   - **② فتح صفحة الاسم** — مسحه يفتح صفحة التسجيل.
3. الطالب يختار اسمه من القائمة ← يظهر له ✅ ويُسجَّل اسمه ووقت حضوره عند المعلّم.
4. في النهاية **تصدير CSV** يرسل الجدول عبر واتساب أو البريد أو يحفظه في الهاتف.

الطلاب يفعلون هذا كلهم في وقت واحد بالتوازي، فتنتهي الحصة كاملة خلال دقيقتين.

## المزايا

- لا يحتاج إنترنت إطلاقًا — لا عند المعلّم ولا عند الطالب.
- الطالب لا يثبّت أي تطبيق، يكفي متصفح هاتفه.
- قائمة الطلاب تُلصق مرة واحدة، فيختار الطالب اسمه بدل كتابته (يمنع الأخطاء الإملائية والتكرار).
- يقبل كتابة الاسم يدويًا إذا لم تُحمّل قائمة.
- يتعرّف على اختلافات الهمزة والتاء المربوطة والتشكيل عند مطابقة الأسماء.
- تصدير CSV يفتح مباشرة في Excel.
- ضغطة مطوّلة على أي اسم في السجل تحذفه.

## بناء ملف APK

يُبنى تلقائيًا عبر GitHub Actions عند كل رفع إلى `main`.
الملف الناتج موجود في:

- **Releases** ← آخر إصدار ← `hudur-attendance.apk`
- أو **Actions** ← آخر تشغيل ← قسم Artifacts

أو محليًا بوجود Android Studio:

```bash
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## الأذونات

- **الموقع (ACCESS_FINE_LOCATION)** — يفرضه نظام اندرويد لتشغيل شبكة Wi-Fi محلية. لا يُستخدم لتتبّع المكان.
- **Wi-Fi والشبكة** — لتشغيل الشبكة المحلية والخادم.

لا يُرسل التطبيق أي بيانات إلى أي خادم خارجي. كل شيء داخل الهاتف.

## البنية

| الملف | الوظيفة |
|---|---|
| `MainActivity.kt` | الواجهة، تشغيل الشبكة المحلية، توليد رموز QR، التصدير |
| `AttServer.kt` | خادم HTTP محلي على المنفذ 8080 |
| `Store.kt` | تخزين قائمة الطلاب وسجل الحضور داخل الهاتف |
| `assets/student.html` | الصفحة التي تُفتح على هاتف الطالب |
